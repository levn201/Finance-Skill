# earnings scenarios

Run these in Claude Code and Gemini CLI, with `FINANCIAL_SUPPORT_HOME` pointing to a temporary folder that holds a Depot with SAP.DE (with a Thesis) and AAPL.

## 1. Preview

> Was wird von den nächsten SAP-Zahlen erwartet?

Expected:
- The date is marked as an estimate unless confirmed on SAP IR
- EPS and revenue consensus with range
- The downward EPS revision is mentioned
- What to watch, mapped to the Thesis pillars
- The beat history and typical move, with the "beat but fell" cases explained
- A scenario table
- Sources

## 2. Review of a beat-and-drop

> Warum ist SAP im Januar 2026 trotz guter Zahlen so stark gefallen?

Expected:
- The −13 % reaction around 2026-01-29 from the track record
- The causes researched (guidance, cloud metrics), with confirmed and interpreted points separated

## 3. ISIN input

> Wie waren die letzten Zahlen von US0378331005?

Expected:
- The ISIN resolves to AAPL
- Review mode for the latest reported quarter, with actual versus estimate and the price reaction

# Scope is a single private investor, not financial-services professionals

The upstream project targets bankers, analysts and fund admins drafting work product for clients. This project serves one private investor managing their own money, using free public data and their own files. So we take over only the equity-research and core valuation skills (catalysts, earnings preview/analysis, idea generation/screening, thesis tracking, sector overview, morning note, DCF, comps, competitive analysis). We deliberately drop investment banking, private equity, fund admin, KYC/operations, the LSEG and S&P partner plugins, PPTX/pitch-deck tooling, LBO, M365 tooling and Managed Agent deployment, together with all paid data connectors.

Unlike upstream, the assistant does give Assessments (buy/hold/sell with reasons), because the investor decides for themselves and wants a clear view. It still never sizes positions.
